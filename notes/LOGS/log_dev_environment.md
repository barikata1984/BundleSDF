# 作業ログ: 開発環境 (Claude Code)

## 2026-07-05: ステータスバー不具合の FTA 調査 (jq 未インストール)

Claude Code のステータスバー (`~/.claude/statusline-command.sh`) が `🤖 Unknown` / `📐 CTX ... 0%` / `💰 --` のように, モデル名・コンテキスト使用率・行数差分・コストの全てでデフォルト値にフォールバックする不具合を, Fault Tree Analysis (FTA) の手順で調査した.

Top event は, ステータスラインスクリプトがモデル名・コンテキスト使用率・行数差分・コストの全フィールドでデフォルト値にフォールバックしていたことである. モデル名・cwd・git 統計・コストを全て含む正常なモック JSON を与えても同じ症状 (`Unknown`/`0%`/`--`) が再現したため, JSON スキーマの不一致が原因である可能性は排除できた.

根本原因は, 実行コンテナに `jq` コマンドが未インストールだったことである. スクリプト内の `parse_json()` は `jq` の出力を `result=$(... | jq ...) || result=""` という形でラップしており, `jq` が存在しない場合 (exit 127) もエラーとして落ちずに空文字へ静かにフォールバックし, 各フィールドがデフォルト値 (`Unknown`, `0`, `100` など) になる設計だった.

恒久対応として, `docker/dockerfile` の apt-get install リスト (44行目付近, `git`/`vim`/`tmux` 等と同じブロック) に `jq` を追加した. これによりイメージの次回ビルドから `jq` が導入されるようになる. 一時対応として, 稼働中のコンテナには `apt-get update && apt-get install -y jq` を実行済みで, モデル名・CTX バー・コスト等を全て含むモック JSON により正しく表示されることを動作確認済みである.

本件はプロジェクト本体 (BundleSDF/ROS One 移行) のコードではなく, 開発環境の Claude Code ツール設定に関するものである.
